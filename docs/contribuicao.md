# Contribuição

Este documento propõe o fluxo de trabalho; configurações não foram verificadas como existentes. [Voltar ao README](../README.md).

Use `main` protegida, branch curta por cartão, commit semântico, revisão por colega e checks de lint, build e testes em GitHub Actions. Antes de publicar, verificar a aplicação no ambiente público e registrar a evidência. Exemplo de cartão: `P02 Reservar última mesa sem duplicidade`, aceite: duas requisições concorrentes produzem uma confirmação. Exemplo de PR: contexto, solução, testes executados, limitações e roteiro de revisão.

Use IA para uma tarefa delimitada, registre prompt e decisão humana em [prompts](prompts/README.md) e revise cada linha. O autor deve conseguir explicar o código que assina.
