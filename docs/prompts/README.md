# Registro de prompts

Este arquivo explica como registrar uso de IA sem inventar histórico. [Voltar ao README](../../README.md).

Para cada uso, crie um registro com: data, autor, objetivo da tarefa, prompt relevante, arquivos afetados, decisão humana, revisão realizada e verificação. O prompt deve ser específico ao cartão; o autor continua responsável pela compreensão e pelo resultado.

Modelo:

```md
# PXX — título
Autor: nome | Data: AAAA-MM-DD
Objetivo: ...
Prompt: ...
Decisão humana: ...
Arquivos: ...
Verificação: ...
```
